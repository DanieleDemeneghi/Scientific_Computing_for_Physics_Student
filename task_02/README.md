## Short description of the folder content

vecsum and matmul refer to the files with the daxpy vector addition and matrix multiplication respectively.



To compile the files use:



`gcc vecsum.c -o vecsum.exe`



and



`gcc matmul.c -o matmul.exe`



task\_02\_answer.md has the answers to the questions posed in the task02-computational\_hello\_world.pdf file.
